# Gravity Model of International Trade

## Overview

This project analyzes international trade flows using the Gravity Model in R.

The objective is to identify the main determinants of bilateral trade between countries through panel data econometric models.

## Objectives

- Analyze international trade flows
- Estimate the Gravity Model
- Compare different panel data estimators
- Interpret the impact of economic variables on trade

## Econometric Models

- Ordinary Least Squares (OLS)
- Fixed Effects (Within)
- Between Effects
- Random Effects

## Data Sources

- World Bank
- International trade databases

## Technologies

- R
- plm
- dplyr
- ggplot2
